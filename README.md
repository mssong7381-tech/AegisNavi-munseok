## 💡 주요 테스트 질의 예시

1. **집계형 (Text-to-SQL)**:
   - *"한바다호의 2024년 전체 정비 작업 건수는 몇 건인가요?"*
   - *"2024년 선박별 누적 정비 비용 순위를 보여줘"*
   - *"아라호에서 가장 정비가 많이 발생한 기기 상위 5개는?"*
2. **후속 질문 해석 (대화 이력 재작성)**:
   - (이전 질문에 이어) *"그거 비용은?"* → 선박 및 기기명을 특정하여 자동으로 3인칭 완전 문장 재작성 후 실행
3. **절차형 (RAG + 인용 검증)**:
   - *"주기관 실린더 커버 분해 절차와 규정 유압 토크값은?"*
   - *"연료유 청정기 볼 분해 소탕 방법 및 주의사항 알려줘"*
4. **기권 판정 (알수없음 테스트)**:
   - *"원자로 냉각재 순환 펌프의 정비 지침은?"*
   - *"우주선 추진체 밸브 교체 비용은 얼마인가요?"*
   - → 시스템이 자동으로 근거 부재(조건 F 충족)를 감지하여 **'알수없음'**으로 안전하게 기권합니다.
